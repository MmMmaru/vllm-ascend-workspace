注意：`vllm-ascend-main/` 是本地 linked worktree，不属于 parity 管理范围，
已加入根仓库 `.gitignore`。parity 同步的是根仓库及其 `vllm/`、`vllm-ascend/`
子模块；不要把 `vllm-ascend-main/` 手工复制到 `/vllm-workspace`，否则其中指向
Windows 路径的 `.git` 文件会被远端 `git clean` 扫描并导致同步失败。

如果远端已经存在这个历史残留目录，第一次修复时应先将其移到
`/vllm-workspace/.vaws-runtime/` 下备份，再执行 parity 同步；确认根仓库的
`.gitignore` 已同步后，如启动脚本仍需要该独立 worktree，可恢复到
`/vllm-workspace/vllm-ascend-main`，它会被忽略且不再参与 `git clean`。
